# Career Baller

Quero criar um jogo web chamado Project Football Career.

Antes de começar a desenvolver funcionalidades, quero criar uma base sólida e profissional.

Leia este prompt como a definição oficial do projeto.

==================================================

CONCEITO

==================================================

Project Football Career é um simulador de carreira de jogador de futebol.

O jogador controla apenas a carreira de um atleta.

Ele NÃO controla clubes.

Ele NÃO controla partidas.

As partidas são simuladas automaticamente.

O foco do jogo é tomar decisões inteligentes durante a carreira.

==================================================

OBJETIVO

==================================================

O jogador começa sem clube e precisa construir sua carreira através de peneiras, desempenho, evolução e boas decisões.

O objetivo final é viver uma carreira completa, disputar grandes competições, conquistar títulos, ser convocado para a seleção e construir um legado até a aposentadoria.

==================================================

TECNOLOGIAS

==================================================

Utilizar:

- React

- TypeScript

- Tailwind CSS

Criar código limpo, organizado e preparado para expansão.

==================================================

ARQUITETURA

==================================================

Criar uma estrutura profissional.

Separar interface da lógica.

Criar componentes reutilizáveis.

Criar um sistema global de estado.

Criar um sistema de navegação.

Criar um sistema de salvamento.

Criar um sistema de calendário.

Criar um sistema preparado para dezenas de temporadas.

Todas as entidades devem possuir IDs únicos.

==================================================

INTERFACE

==================================================

A interface deve parecer um jogo moderno.

Não quero aparência de sistema administrativo.

Utilizar:

- Cards

- Ícones

- Barras de progresso

- Boa hierarquia visual

- Animações suaves

- Tema escuro elegante

==================================================

MENU PRINCIPAL

==================================================

Criar apenas estas opções:

Novo Jogo

Continuar

Configurações

Créditos

==================================================

NOVO JOGO

==================================================

Permitir criar um jogador.

Campos:

Nome

Sobrenome

Data de nascimento (idade entre 11 e 20 anos)

Nacionalidade

Posição

Pé dominante

Ao finalizar, criar uma carreira nova e salvar automaticamente.

==================================================

NÃO IMPLEMENTAR AINDA

==================================================

Ainda NÃO criar:

- peneiras

- clubes

- transferências

- empresários

- lesões

- campeonatos

- seleções

- mercado

- evolução

Quero apenas uma fundação extremamente organizada para receber esses sistemas futuramente.

O projeto deve ser preparado para crescer sem precisar ser reestruturado.
